# Урок 00 · Введение — фундамент + первый бот · РАЗДАТКА

## 0. Что ты получишь

За этот урок ты соберёшь **первого живого Telegram-бота**: он берёт курс юаня (CNY/RUB) по публичному API и подаёт его **голосом твоего бизнеса** в Telegram. Не сухая цифра, а факт с характером бренда. Бот запускается и живёт без тебя — первый опыт «оно работает само».

**В паке:**
- 2 промпта: П1 (голос бизнеса из сырого факта) и П2 (объясни как для бизнеса, без терминов).
- Рецепт мини-бота по 3 кубикам (no-code, пошагово).
- Шаблон «карточка бизнеса» — пустой + заполненный пример.
- Мини-словарь: API, JSON.
- Карта-справочник — навигатор на весь курс.
- Чеклист участника и частые ошибки.

## 1. Промпты (copy-paste ready)

#### П1 · Голос бизнеса из сырого факта
*Когда применять: у тебя есть сухой факт (цифра, курс, новость) и надо превратить его в короткое сообщение голосом твоего бренда.*

```
Ты — редактор, который пишет короткие сообщения в Telegram голосом конкретного бизнеса.

БИЗНЕС: [описание бизнеса: чем занимается, например «мебельный цех, делает корпусную мебель на заказ»]
ТОН: [деловой / лёгкий]
ЦЕЛЕВАЯ АУДИТОРИЯ: [кто читает, например «закупщик мебельного производства»]

ВХОДНОЙ ФАКТ (единственный источник данных):
[сырой факт от API, например «CNY/RUB = 12.4, +0.3 за сутки»]

ЗАДАЧА:
Перепиши входной факт как одно короткое сообщение в Telegram голосом этого бизнеса.
Добавь один уместный практический смысл для целевой аудитории (что ей с этим фактом делать).

ПРАВИЛА:
- 1–2 предложения, не длиннее.
- Без канцелярита и штампов, живым языком.
- НЕ выдумывай никаких цифр, прогнозов и фактов. Используй ТОЛЬКО числа из входного факта.
- Держи заданный тон.
- Если во входном факте нет числа — не придумывай его, напиши сообщение без конкретных цифр.

ФОРМАТ ОТВЕТА:
Выведи ТОЛЬКО текст готового сообщения. Без заголовков, без пояснений, без кавычек вокруг.
```

**Что подставить:**
- `[описание бизнеса]` — одна фраза: чем занят бизнес.
- `[деловой / лёгкий]` — выбери один тон.
- `[кто читает]` — конкретная роль твоего читателя.
- `[сырой факт от API]` — то, что вернул источник (курс + изменение).

**Вариант адаптации:**
- Добавь строку `ДЛИНА: 1 предложение` — если нужны совсем короткие пуши.
- Замени факт-курс на любой другой (остаток на складе, новый заказ, погода для доставки) — структура та же.

#### П2 · «Объясни как для бизнеса, без терминов»
*Когда применять: ИИ отвечает заумно, с терминами. Вставляешь эту рамку — и он говорит человеческим языком. Работает весь курс.*

```
Отвечай так, будто объясняешь владельцу малого бизнеса без технического бэкграунда:
- без терминов;
- короткими предложениями;
- с одной бытовой аналогией.
Если без термина никак — сразу расшифруй его в скобках простыми словами.

Мой вопрос: [твой вопрос]
```

**Что подставить:**
- `[твой вопрос]` — что именно хочешь понять.

**Вариант адаптации:**
- Можно вставлять эту рамку **сверху** любого другого промпта как многоразовую «настройку тона» — тогда весь ответ будет на человеческом языке.

## 2. Шаблоны и заготовки

### Шаблон «Карточка бизнеса» (для П1)

Пустой:

| Поле | Значение |
|---|---|
| Чем занимается бизнес | [___] |
| Тон (деловой / лёгкий) | [___] |
| Кто читает (ЦА) | [___] |
| Какой факт подаём | [___] |

Заполненный пример (наш пример на весь урок):

| Поле | Значение |
|---|---|
| Чем занимается бизнес | Мебельный цех, корпусная мебель на заказ |
| Тон | Деловой |
| Кто читает (ЦА) | Закупщик мебельного производства |
| Какой факт подаём | CNY/RUB = 12.4, +0.3 за сутки |

→ Ответ П1: «Юань подрос до 12.4 (+0.3 за сутки) — если брали фурнитуру из Китая, самое время пересчитать закупку, пока не уехало дальше.»

### Мини-словарь

- **API** — способ, которым одна программа спрашивает данные у другой (как окошко: подошёл, спросил курс — назвали, а как банк внутри устроен, знать не надо).
- **JSON** — формат, в котором приходят эти данные: аккуратный список пар «название: значение», читаемый и человеку, и компьютеру.

### Карта-справочник (навигатор на весь курс)

Не читай подряд. Ты падаешь сюда по врезке из блока, читаешь нужную карточку за пару минут — и возвращаешься в практику. В скобках — блок, где понятие раскрывается вглубь.

| Карточка | Что это в одну строку | Блок |
|---|---|---|
| Чтение открытых источников | ИИ читает публичные посты/объявления и достаёт оттуда сигналы — без сбора базы, только откликнувшимся. | 01 |
| Входящий vs холодный | Входящий сам поднял руку; холодного трогаем только в законной рамке — читаем открытое, пишем откликнувшимся. | 01 |
| Данные из файлов | Скармливаешь ИИ прайс/таблицу/PDF — он работает с твоими данными, а не из головы. | 04 |
| Внешний API и когда его нет | Берём данные из чужого сервиса по API; если API нет — обходные пути (файл, ручной ввод). | 04 |
| Запись во внешний сервис | Бот не только читает, но и пишет: заводит событие в календарь, задачу в трекер, карточку в CRM. | 03 |
| Память | Бот помнит контекст между сообщениями — кто писал, о чём договорились. | 02/03 |
| Планировщик | Бот сам просыпается по расписанию (каждое утро, раз в час) и делает работу без тебя. | 02/05 |
| Пороги и алерты | Реагируем не на всё, а когда показатель перешёл порог: «курс скакнул больше 2% — дай знать». | 05 |
| Балл по тексту (скоринг) | ИИ оценивает текст баллом прямо в моменте (насколько горячий лид). Балл считается на лету и растворяется — картотеки на людей не заводим. | 02 |
| Промпт-инъекции | Чужой текст пытается перехватить твоего бота командой внутри сообщения; учимся это отсекать. | 03 |
| Бот представляется ботом | Бот честно говорит, что он **цифровой сотрудник** компании, а не живой человек — это требование к голосовым и чат-ботам. | 03 |
| Технология голоса бизнеса | Тот самый приём из этого урока: сырой факт → ИИ переписывает голосом бренда (П1). | 03 |

## 4. Как собрать артефакт (мастер-промпт)

*Это промпт, который собирает всё вместе: источник → голос бизнеса (П1) → отправка → расписание. Подставь свои вводные в [скобках]. Если сервис или база у тебя нестандартные — приложи к промпту их документацию, агент разберётся. Ручной рецепт по кубикам — ниже, в разделе 5 (деплой).*

#### М · Сборка бота «курс голосом бизнеса»

```
Ты — мой агент-сборщик. Собери и запусти маленький артефакт: раз в [период: напр. раз в час] бери
свежий факт из источника, переписывай его голосом моего бизнеса и отправляй в мой канал.

ИСТОЧНИК ДАННЫХ:
[источник: публичный API курса — URL, напр. курс CNY/RUB от ЦБ РФ или публичный exchange API, без ключа]
Прочитай оттуда нужное число и его изменение за период. Приведи к виду сырого факта,
например «CNY/RUB = 12.4, +0.3 за сутки».

ОБРАБОТКА (голос бизнеса):
Возьми сырой факт и перепиши его по промпту П1 (Голос бизнеса из сырого факта) из этой раздатки.
Моя карточка бизнеса для П1:
- Бизнес: [описание бизнеса, напр. «мебельный цех, корпусная мебель на заказ»]
- Тон: [деловой / лёгкий]
- Кто читает: [роль читателя, напр. «закупщик мебельного производства»]
Правила П1 соблюдай строго: НЕ выдумывай цифр, используй только числа из факта, 1–2 предложения.
Если ответ вышел заумным — прогони его через рамку П2 («объясни как для бизнеса, без терминов»).

ОТПРАВКА:
Отправь готовое сообщение своим инструментом в [канал отправки: мой Telegram-канал/чат — id/ссылка].
Доступ на отправку: [доступ: токен Telegram-бота от @BotFather].

РАСПИСАНИЕ:
Запускай этот цикл [период: напр. раз в час]. Для проверки сначала сделай один прогон вручную,
покажи мне результат — и только после моего «ок» ставь на расписание.

СТРАХОВКА (обязательно соблюдай):
- Если нужного сервиса/API/БД я не знаю или он у меня нестандартный — приложи его документацию
  (API-доки, схему, пример ответа), и я разберусь, как подключиться и что читать.
- Если у тебя (агента) нет нужного инструмента или доступа (например, отправки в Telegram) —
  сначала скажи, что подключить, и НЕ выдумывай данные и не имитируй отправку.
- Если источник вернул пусто/ошибку — не придумывай число: скажи, что источник недоступен,
  и предложи запасной публичный API или ручной ввод факта.
```

**Что подставить:**
- `[период]` — как часто гонять цикл (раз в час / раз в день / по утрам).
- `[источник]` — URL публичного API курса (ЦБ РФ или любой exchange API без ключа).
- `[описание бизнеса]`, `[деловой / лёгкий]`, `[кто читает]` — твоя карточка бизнеса для П1 (шаблон в разделе 2).
- `[канал отправки]` — куда падает сообщение: id или ссылка твоего Telegram-канала/чата.
- `[доступ]` — токен бота от @BotFather.

**Что подключить:**
- Инструмент отправки в **Telegram** — токен бота от **@BotFather** (команда `/newbot`, потом `/token`). Храни как пароль.
- Доступ агента в **интернет** — чтобы дёрнуть публичный API курса (ключ не нужен).
- Если твоего источника или канала нет среди инструментов агента — приложи документацию/пример ответа, агент подстроится (это и есть страховочные строки в промпте).

**Запуск:**
- Режим — **по расписанию** (`[период]`). Для первого раза скажи агенту сделать один прогон вручную и показать результат; после «ок» — ставить на расписание.
- Дальше бот живёт сам: можно закрыть ноутбук. Ручная сборка тех же кубиков по шагам — в разделе 5 ниже.

## 5. Как запустить (деплой) — рецепт мини-бота по 3 кубикам

Собираем no-code, пошагово, не углубляясь в каждую кнопку.

**Кубик 1 · Источник (API курса CNY/RUB)**
1. Открой ссылку публичного API курса (API ЦБ РФ или публичный exchange API — без ключа).
2. Убедись, что он отдаёт JSON с курсом юаня и изменением за сутки.
3. Это твой сырой факт вида `CNY/RUB = 12.4, +0.3 за сутки`.

**Кубик 2 · Обработка (промпт П1)**
1. Возьми промпт **П1**.
2. Подставь свою карточку бизнеса (шаблон выше) и сырой факт из кубика 1.
3. Получи короткое сообщение голосом бизнеса. Проверь: нет ли выдуманных цифр.

**Кубик 3 · Доставка (Telegram-бот)**
1. В Telegram открой **@BotFather** → команда `/newbot` → задай имя и username.
2. Получи **токен** — это ключ от бота. Храни как пароль, никому не показывай.
3. Свяжи в no-code-сцепке: источник → П1 → отправка сообщения ботом в твой чат.
4. Запусти. Сообщение падает в Telegram.

**Автономность:** мини-бот запускается и живёт — можно закрыть ноутбук, он продолжит работать по расписанию. Это первый опыт «работает без меня». Тот же принцип деплоя будет во всех блоках, здесь — на самом простом примере.

## 7. Частые ошибки

- **Если** в ответе появилась цифра, которой не было во входе — **то** промпт «дорисовал». Проверь правило «НЕ выдумывай цифр» в П1, перезапусти. Никогда не публикуй прогноз, который придумала модель.
- **Если** ответ длинный и с канцеляритом — **то** ты потерял правило «1–2 предложения» или тон. Верни их в П1.
- **Если** бот молчит — **то** чаще всего неверный или не сохранённый токен. Пересоздай токен у @BotFather (`/token`) и подставь заново.
- **Если** токен где-то засветился (в скрине, в чате) — **то** сразу отзови его у @BotFather и выпусти новый: токен = полный доступ к боту.
- **Если** API вернул пусто/ошибку — **то** источник временно недоступен. Возьми запасной публичный exchange API или подставь факт вручную для теста.
- **Если** хочется, чтобы бот считал себестоимость по курсу — **то** это уже блок 04 (данные из файлов, прайсы). В 00 бот только **комментирует курс голосом**, а не считает.
