# Ежедневная проверка контрагентов — установка

Три файла:
- `daily_check_prompt.md` — сам промпт (задача) для Claude Code.
- `run_daily_check.sh` — обёртка для запуска из cron (блокировка, логи, .env).
- `.env` (создайте сами, см. ниже) — секреты.

Как это работает: каждый день вы (или любой другой процесс) кладёте новый
файл `.xlsx`/`.csv` с таблицей контрагентов в `input/`. По расписанию Claude
Code headless-режимом (`claude -p`) читает файл, проверяет каждую компанию по
ИНН через Apify-актор `isolovyev/ru-counterparty-check` и проверяет наличие
отзывов на 2ГИС через `m_mamaev/2gis-places-scraper`, и сохраняет отчёт в
`output/report_<дата>.md`.

## 1. Предварительные требования

- Установлен Claude Code (`npm install -g @anthropic-ai/claude-code`) и вы
  залогинены (`claude login`) под аккаунтом с активной подпиской — этого
  достаточно для cron на этой же машине, отдельный токен не нужен.
- Токен Apify: Apify Console → Settings → Integrations → **API token**.

## 2. Секреты

Создайте файл `.env` рядом со скриптом (не коммитьте его в git):

```bash
APIFY_TOKEN=apify_api_xxxxxxxxxxxxxxxxxxxx
```

## 3. Проверка вручную (перед тем как ставить в cron)

```bash
cd daily-contractor-check
cp /путь/к/сегодняшнему/файлу.xlsx input/
./run_daily_check.sh
cat output/report_$(date +%F).md
```

Если всё ок — отчёт появится в `output/`, а строка в `logs/cron.log`
подтвердит успешный прогон.

## 4. Планирование на 10:00 по Москве

Россия не переходит на летнее/зимнее время — MSK всегда UTC+3, поэтому
10:00 МСК = 07:00 UTC круглый год.

### Вариант А — Linux/macOS, cron (самый универсальный)

```bash
crontab -e
```

Добавьте (укажите свой абсолютный путь):

```cron
# Если сервер живёт в UTC:
0 7 * * * /home/user/daily-contractor-check/run_daily_check.sh

# Если удобнее задать по МСК явно — добавьте TZ отдельной строкой в crontab
# (поддерживается большинством современных cron, напр. Ubuntu/Debian):
TZ=Europe/Moscow
0 10 * * * /home/user/daily-contractor-check/run_daily_check.sh
```

Проверить часовой пояс сервера: `timedatectl` (Linux) или `date`.

### Вариант Б — macOS/Windows, Desktop Scheduled Tasks (без cron)

Если Claude Code Desktop установлен на машине с системным временем по МСК —
проще воспользоваться встроенным планировщиком:

1. В Claude Code Desktop откройте **Schedule** в сайдбаре → **New task**.
2. Working folder — папка `daily-contractor-check`.
3. Prompt — вставьте содержимое `daily_check_prompt.md`.
4. Frequency — Daily, время — 10:00.
5. Разрешите инструменты Read/Write/Bash(curl) в настройках задачи.

Ограничение: такие задачи работают только пока компьютер включён (в отличие
от cron на сервере или облачных Routines).

### Вариант В — Windows, Task Scheduler + cron-обёртка

Используйте `wsl.exe` или Git Bash для запуска `run_daily_check.sh`, триггер
— «Ежедневно, 10:00» (если системное время машины — МСК).

## 5. Стоимость одного прогона

Ориентировочно на 5 компаний: проверка по ИНН — около **$0.10**
($0.02 × 5), проверка 2ГИС — около **$0.03–0.10** в зависимости от числа
совпадений и отзывов. Итого центы, не доллары — но именно поэтому в
`run_daily_check.sh` стоит `--max-budget-usd 1.00`, чтобы случайно большой
файл не привёл к неожиданному счёту.

## 6. Если что-то пошло не так

- `logs/run_<timestamp>.err` — технические ошибки Claude Code.
- `logs/run_<timestamp>.json` — полный ответ (включая `total_cost_usd`).
- `logs/cron.log` — короткая история запусков.
- Частая причина «пусто» в отчёте: файл в `input/` уже упомянут в
  `processed.log` — удалите строку, если нужно перепроверить тот же файл.
