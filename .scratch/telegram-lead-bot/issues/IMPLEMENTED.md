# Реализация 2026-08-12 — отклонение от generic-спеки в пользу og1

`spec.md` в этой папке — generic-версия (нейтральный бизнес, кнопка «Оплатил ✅»,
абстрактный прайс). Пользователь 2026-08-12 явно сузил область работы до **og1**
(«удали про biorich только работать будем по og1») и подтвердил переход к коду на
заглушках, специфичных под og1 (`og1/PLAN.md`), а не абстрактных «Товар А/Б». Тикеты
по generic-спеке отдельно не писались — реализация пошла сразу под og1-вариант.

## Второй раунд решений (2026-08-12, продолжение той же сессии)

4. **Priority Score/production-очередь** — не реализовывать для og1, это не подтверждённая
   потребность, а лишь аналогия из PLAN.md.
5. **lead-catcher-auto VK-токен** — скрипт-хелпер (`vk_login.py`, Implicit Flow OAuth с ручной
   вставкой redirect-URL), не чистый ручной OAuth без кода.
6. **lead-catcher-auto рейт-лимиты** — для MVP просто ждать `FloodWaitError`/VK code 6 и
   продолжать, без ротации аккаунтов/прокси.

При реализации найден и исправлен баг: `main.py` создавал `TelegramClient` безусловно ещё до
проверки `TG_API_ID`/`TG_API_HASH`, что роняло процесс на плейсхолдерных (пустых) кредах;
и `config.py` не вызывал `load_dotenv()`, поэтому `.env` фактически не читался никаким модулем.
Оба бага исправлены и проверены живым запуском `main.py` без единого реального ключа — процесс
стартует, CRM (`/` и `/catcher`) отвечает 200, userbot/бот-хэндофф корректно пропускаются с
warning в логе вместо падения.

## Решения, зафиксированные перед стартом кода (грилинг 2026-08-12)

1. **ПДн детей** — храним минимально, без деталей ребёнка. Юридическая проверка 152-ФЗ
   всё равно нужна до боевого запуска с реальными лидами.
2. **Оплата og1** — бот доводит до передачи менеджеру приёмной комиссии, не завершает
   сделку сам (подписка + рассрочка + договор не укладываются в кнопку «Оплатил»).
3. **Данные og1** — тарифы/боли/слова-сигналы берём из `og1/PLAN.md` (реальные факты с
   сайта), а не абстрактные заглушки.

## Что осталось плейсхолдером (ждёт боевых данных от заказчика)

- Ставка репетитора и % накладных/наценки в `kp.py` (`TUTOR_RATE_PLACEHOLDER`, `OVERHEAD_PCT`, `MARKUP_PCT`).
- Тексты Шаблона А и воронка этапов в `prompts.py` (`TEMPLATE_A_OG1`, `FUNNEL_STAGES_OG1`) — черновой тон, не сверен с заказчиком.
- Слова-сигналы для групп (`config.py GROUP_SIGNAL_WORDS`).
- `TG_API_ID/HASH`, `BOT_TOKEN`, `ANTHROPIC_API_KEY`, `OPERATOR_CHAT` — секреты, только в `.env`.
